# بنزین، مسکن و نابرابری فضایی — گزارش تعاملی

گزارش تعاملی فارسی (تک‌صفحه‌ای، بدون سرور) درباره این پرسش که آیا بخشی از مصرف بالای بنزین ایران،
هزینه انرژیِ فاصله‌ای است که بحران مسکن میان محل زندگی و محل کار ایجاد کرده است.

## اجرا

این پروژه یک سایت استاتیک خالص است؛ هیچ وابستگیِ زمان‌اجرا یا مرحله بیلد ندارد.

```bash
# اجرای محلی (درواقع هر سرور استاتیک کافی است)
python3 -m http.server 8901
# سپس: http://localhost:8901/
```

یا به‌سادگی `index.html` را در مرورگر باز کن (فایل‌ها به‌صورت کلاسیک لود می‌شوند).

## ساختار

```
index.html                  صفحه اصلی (کل روایت + شکل‌های تعاملی)
housing-price.html          صفحه مستقل: قیمت مسکن در برابر ارز و تورم (فصلی، پایهٔ مشترک، تولیدشده)
rent-vs-fx.html             صفحه مستقل: اجاره در برابر ارز (فعلاً رشد اجارهٔ تهران ۱۳۹۰–۱۴۰۰، تولیدشده)
rent-drivers.html           صفحه مستقل: چرا اجاره گران می‌شود؟ (دلار/مسکن/اجاره فصلی ۱۳۹۶–۱۴۰۳، تولیدشده)
css/style.css               استایل (راست‌چین، تیره، Vazirmatn)
js/                         منطق (util، views، article)
data/                       داده‌ها + فرض‌ها (منبع حقیقت)
  annual.csv                سری‌های سالانه (بنزین، اجاره، قیمت مسکن، حداقل دستمزد)
  tehran_rent_district.csv  اجاره فصلی ۲۲ منطقه تهران ۱۳۸۸–۱۴۰۰ (خروجی اسکریپت)
  periphery.csv             رشد ساخته‌شده پیرامون و شاخص‌های کارکردی
  sources.csv               منبع هر عدد/ادعا
  assumptions.json          همه فرض‌های مدل (بدون ثابت بی‌توضیح در کد)
  data.js                   باندل تولیدشده (از csv/json بالا) — ویرایش دستی نکن
  housing_price/            شاخص فصلی مسکن/ارز/تورم + جدول فصلی ارز و تورم (خروجی اسکریپت)
  rent_vs_fx/               سری سالانهٔ اجارهٔ تهران + شاخص و رشد سالانه (خروجی اسکریپت)
  rent_drivers/             پنل فصلی دلار/مسکن/اجاره ۱۳۹۶–۱۴۰۳ + رشد سالانه (خروجی اسکریپت)
assets/geo/tehran_districts.js  هندسه ساده‌شده مناطق ۲۲گانه (تولیدشده)
scripts/build_data.py       بازتولید tehran_rent_district.csv و data.js
scripts/build_housing_price_index.py  بازتولید data/housing_price/* و housing-price.html
scripts/build_rent_vs_fx.py بازتولید data/rent_vs_fx/* و rent-vs-fx.html
scripts/build_rent_drivers.py  بازتولید data/rent_drivers/* و rent-drivers.html
docs/                       دست‌نوشته‌های پژوهشی/بازبینی
```

**صفحه `housing-price.html`:** سه سری فصلی (قیمت پیشنهادی فروش مسکن تهران از کیلیک، نرخ ارز آزاد،
شاخص تورم CPI با پایهٔ ۱۴۰۰=۱۰۰) روی یک محور، همه با پایهٔ ثابت تابستان ۱۴۰۰ = ۱۰۰ (دکمهٔ انتخاب پایه وجود ندارد).
هر سه سری دقیقاً بازهٔ یکسانی دارند — تابستان ۱۴۰۰ تا تابستان ۱۴۰۵، ۲۱ فصل — چون هم سری ماهانهٔ
کیلیک و هم جدول ارز/تورم از `1400-06` آغاز می‌شوند؛ هیچ مقداری درون‌یابی یا جعل نشده است.
هر خط را می‌توان از راهنما خاموش/روشن کرد؛ **خط مسکن به‌طور پیش‌فرض خاموش است و برچسب «منبع کم‌اعتماد» دارد**،
چون سری کیلیک در اردیبهشت ۱۴۰۲ یک شکست سطحی سراسری دارد و منطقهٔ ۱ در بهمن ۱۴۰۱ تا فروردین ۱۴۰۲ خراب است.
جزئیات روش و محدودیت‌ها در `data/housing_price/README.md`.

**صفحه `rent-vs-fx.html`:** چهار سری سالانه روی یک نمودار دوبار محوره، ۱۳۹۰ تا ۱۴۰۰ (۱۱ نقطه)، همه با پایهٔ
ثابت ۱۳۹۰ = ۱۰۰ — نرخ ارز آزاد، شاخص تورم CPI، اجارهٔ تهران و اجاره به دلار (محور راست). «شکاف قیچی‌ای»
همان فاصلهٔ ارز از تورم و اجاره است: ارز ×۲۳٫۳۳، تورم ×۸٫۶۴، اجاره ×۶٫۵۵ و اجاره به دلار ×۰٫۲۸ (از ۱۰٫۸ به
۳٫۰ دلار بر متر مربع). هر خط را می‌توان از راهنما خاموش/روشن کرد و مقیاس محور عمودی خطی/لگاریتمی است.
ورودی‌ها: اجاره از `data/annual.csv` (متغیر `tehran_rent`، منبع S2) و ارز و تورم از
`data/rent_vs_fx/fx_inflation_annual.csv` (منبع S16، project-supplied).
دو هشدار مهم: شاخص CPI در سند تحویل با ستون تورم خودش نمی‌ساخت و در این صفحه از خود تورم بازساخته می‌شود،
و سری اجاره با سری فصلی ۲۲ منطقه (شکل ۲ صفحهٔ اصلی) و با `data/rent_wage_index.csv` یکی نیست —
جزئیات در `data/rent_vs_fx/README.md`.

**صفحه `rent-drivers.html`:** «چرا اجاره گران می‌شود؟» — دو نمودار از یک پنل فصلی ۱۳۹۶–۱۴۰۳ (۲۹ فصل، منبع S17):
(۱) خط زمانی سه شاخص (دلار، قیمت مسکن، اجاره) با پایهٔ ثابت بهار ۱۳۹۷ = ۱۰۰ و مقیاس خطی/لگاریتمی، با چهار
علامت زمینه‌ای؛ (۳) ستون‌های رشد سالانهٔ گروه‌بندی‌شده. رشد سالانه از میانگین چهار فصلِ هر سال نسبت به سال قبل
محاسبه می‌شود و از ۱۳۹۸ آغاز می‌گردد (۱۳۹۷ سال پایه است و ۱۳۹۶ فقط یک فصل دارد).
**نمودار دومِ سند تحویل (پراکندگی تأخیر زمانی) عمداً ساخته نشد:** روی سطح، R² در تأخیرهای ۰ و ۱ و ۲ و ۳
تقریباً یکسان بود (۰٫۹۵ تا ۰٫۹۸) و روی تغییرات فصلی به ۰٫۰۲ و ۰٫۱۲ می‌افتاد؛ در فرکانس سالانه حتی علامت
رابطه منفی می‌شد. با این داده هیچ تأخیری قابل اثبات نیست، پس نمودار حذف و ادعای تأخیر از متن‌ها برداشته شد.
جزئیات و جدول کامل در `data/rent_drivers/README.md`.

**نکته:** هر تغییری در داده باید در فایل‌های `data/*.csv` و `data/assumptions.json` انجام شود و سپس
`python3 scripts/build_data.py` اجرا شود تا `data.js` بازتولید شود.
ورودی خام (هندسه مناطق + شاخص دستمزد) در `data/raw/` قرار دارد؛ منبع و یادداشت در `data/raw/README.md`.

## انتشار روی GitHub Pages

مخزن: `https://github.com/hrahmadi/gas-housing`

```bash
git init
git add -A
git commit -m "Interactive Persian article: gasoline, housing & spatial inequality"
git branch -M main
git remote add origin https://github.com/hrahmadi/gas-housing.git
git push -u origin main
```

سپس در GitHub: **Settings ← Pages ← Source: Deploy from a branch ← `main` / `/(root)` ← Save**.
چون همه مسیرها نسبی است و صفحه بدون مرحله بیلد، سایت پس از چند دقیقه روی
`https://hrahmadi.github.io/gas-housing/` در دسترس خواهد بود.

(در صورت تمایل می‌توان به‌جای انتشار از ریشه `main`، یک workflow هم اضافه کرد؛ لازم نیست.)

## وضعیت شکل‌ها

شماره‌گذاری فصل‌ها و شکل‌ها پیوسته و بدون‌گپ است (پس از کامنت‌شدن نقشه مسکن و ماشین‌حساب انرژی، شماره‌ها دوباره‌چین شدند):

- مقدمه (بدون شماره بخش): شکل ۱ = نمودار مصرف روزانه بنزین ۱۳۸۲–۱۴۰۴ (مشاهده‌شده)
- بخش اول · مسکن و جغرافیا: شکل ۲ = شاخص اجاره تهران در برابر حداقل دستمزد (پایه ۱۳۸۸ = ۱۰۰)؛ شکل ۳ = رشد سطح ساخته‌شده منطقه کلان‌شهری تهران ۱۳۸۹–۱۳۹۹ (مشاهده‌شده)
- بخش دوم · مقیاس ملی: شکل ۴ = آزمایش ذهنی «فاصله اضافه سالانه × شاغلین» — از پایه ۸۸ (۱۴۰۰) تا ۱۴۰۵، با خط مرجع مصرف واقعی (≈ ۱۲۹) (سناریو/محاسبه)
- بخش سوم · نمونه پرند: شکل ۵ = شماتیک مسیر پرند–تهران (برآوردی)
- بخش چهارم · شوک قیمت: شکل ۶ = حساسیت به قیمت بنزین (محاسبه/سناریو)
- نقشه تعاملی استطاعت تهران و ماشین‌حساب سوخت: **فعلا از صفحه حذف/کامنت شده‌اند** (کد و داده‌ها سر جایشان هستند)

سه وضعیت در همه شکل‌ها مشخص است: مشاهده‌شده / محاسبه‌شده / برآوردی.

## تم روشن/تیره

یک دکمه در گوشه بالا-راست صفحه (☾ / ☀) تم را بین تیره (پیش‌فرض) و روشن عوض می‌کند. انتخاب در `localStorage` (`gh-theme`) ذخیره می‌شود. همه رنگ‌های صفحه و نمودارهای SVG از متغیرهای CSS در `css/style.css` خوانده می‌شوند (`:root` برای تیره و `html[data-theme="light"]` برای روشن)؛ JS هنگام ترسیم هر شکل، پالت را از همان متغیرها می‌خواند و بعد از تعویض تم، شکل‌ها درجا دوباره رنگ می‌گیرند.
